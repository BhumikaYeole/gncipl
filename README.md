## 📂 Projects Overview  

### 1. 📊 Data Visualization for Olympics Athletes  
- Analyzed Olympic datasets to understand athlete participation and performance across years.  
- Visualized **gender distribution, medal trends, country performance**, and historical comparisons.  
- Tools: Python, Pandas, Matplotlib, Seaborn.  



### 2. 📉 EDA on 2008 Stock Market Crash  
- Performed **Exploratory Data Analysis (EDA)** on stock market data around the 2008 financial crisis.  
- Identified sector-wise losses, volatility, and long-term effects on stock trends.  
- Tools: Pandas, Matplotlib, Plotly.  



### 3. 👥 Customer Segmentation using K-Means  
- Applied **K-Means clustering** to segment customers based on demographics and purchasing behavior.  
- Derived actionable insights for **personalized marketing**.  
- Tools: Scikit-learn, Seaborn, Matplotlib.  



### 4. 🎓 Student Performance Clustering  
- Clustered students based on academic scores and related features.  
- Highlighted patterns in **performance groups** for targeted interventions.  
- Tools: Pandas, Scikit-learn, Matplotlib.  



### 5. 🌸 Iris Flower Classification  
- Built a supervised ML model to classify iris flowers into **Setosa, Versicolor, and Virginica**.  
- Used **Logistic Regression, SVM, and Decision Trees** for comparison.  
- Tools: Scikit-learn, Pandas, Matplotlib.  



### 6. 📧 Spam Email Classifier  
- Developed a **text classification model** to detect spam vs. ham emails.  
- Applied **NLP preprocessing** (tokenization, TF-IDF) with **Naive Bayes classifier**.  
- Tools: Scikit-learn, NLTK, Pandas.
